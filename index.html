Ten-Stage Mathematical Walkthrough

Click toggles to expand individual stages
▶ Stage 1 Matrix Formulation (A x ≈ b)
📌
Concept: Observations as standardized matrix $A \in \mathbb{R}^{n \times d}$ and centered response $b \in \mathbb{R}^n$.
Purpose: Guarantees equal scale weighting across features before computing inner products.
Outcome: Standardized matrix constructed.
$$\text{Design Matrix: } \quad A_{i,j} = \frac{X_{i,j} - \mu_j}{\sigma_j}, \quad b_i = y_i - \bar{y}, \quad A \in \mathbb{R}^{n \times d}$$
Standardized Training Matrix Preview (First 5 Rows) Dimensions: —
▶ Stage 2 Full Gauss-Jordan RREF & Block LU Factorization
📌
Concept: Gauss-Jordan elimination on full matrix $A$; LU factorization with partial row pivoting on leading block.
Purpose: Isolates independent pivot columns and derives explicit linear formulas for free columns.
Outcome: Pivot and free columns identified.
$$\text{RREF: } \quad \text{rref}(A), \qquad \text{Block LU: } \quad P \cdot A_{\text{blk}} = L \cdot U \iff A_{\text{blk}} = P^T L U$$
RREF Leading Block Matrix
▶ Stage 3 Structure of the Space: SVD Numerical Rank & Condition Number
📌
Concept: Singular values $\sigma_i$, numerical rank, nullity, and condition number $\kappa(A) = \sigma_1 / \sigma_r$.
Purpose: Quantifies near-collinearity and numerical inversion stability.
Outcome: Calculated condition number and rank.
$$\text{Dimension Theorem: } \quad \text{rank}(A) + \text{nullity}(A) = d, \qquad \kappa(A) = \frac{\sigma_{\max}}{\sigma_{\min}} \ge 1$$
▶ Stage 4 Basis Selection (Pivoted QR) & Multicollinearity (VIF)
📌
Concept: Maximal linearly independent basis $B \in \mathbb{R}^{n \times r}$; VIF from diagonal of inverse correlation matrix.
Purpose: Prunes exact duplicate columns; flags features with $\text{VIF} > 5$ that inflate estimator variance.
Outcome: Formed full-rank basis matrix B.
$$B = A_{[:, \text{basis}]}, \quad \text{rank}(B) = r = \text{cols}(B), \qquad \text{VIF}_j = \left[(\text{corr}(B))^{-1}\right]_{jj}$$
▶ Stage 5 Modified Gram-Schmidt: Orthonormal Basis Q and Upper Triangular R
📌
Concept: Modified Gram-Schmidt factorization yielding orthonormal $Q$ and upper triangular $R$.
Purpose: Perpendicular columns eliminate geometric correlation; $R$ converts least squares into triangular back-substitution.
Outcome: Constructed Q and R; verified QᵀQ = I.
$$\text{Factorization: } \quad B = Q \cdot R, \quad Q^T Q = I_r, \quad R_{j,j} = \|v_j\|_2 > 0$$
Orthonormal Basis Q Preview Error: machine epsilon
▶ Stage 6 Orthogonal Projection, Hat Matrix Leverage & Cook's Distance
📌
Concept: Projection $\hat{b} = Q (Q^T b)$, residual $e = b - \hat{b}$, hat matrix diagonal leverage $h_i = \text{diag}(Q Q^T)$, and Cook's influence metric.
Purpose: Finds closest reachable point in $\mathcal{C}(B)$; flags influential outlier points pulling the regression fit.
Outcome: Decomposed b = b̂ + e; verified trace(H) = rank.
$$\hat{b} = Q (Q^T b), \quad e = b - \hat{b}, \quad h_i = \sum_{j=1}^r Q_{ij}^2, \quad D_i = \frac{e_i^2}{r s^2} \frac{h_i}{(1 - h_i)^2}$$
▶ Stage 7 Least Squares: QR Solver vs Normal Equations with Standard Errors & CIs
📌
Concept: Solving $R x = Q^T b$ vs $(B^T B) x = B^T b$; standard errors from covariance $\sigma^2 R^{-1} R^{-T}$.
Purpose: QR solves without squaring the condition number; yields analytical 95% confidence intervals.
Outcome: Fitted optimal weights with confidence intervals.
$$\text{QR Estimator: } \quad R x = Q^T b, \qquad \text{Covariance: } \quad \text{Cov}(x) = s^2 (R^T R)^{-1} = s^2 R^{-1} R^{-T}$$
Feature Name QR Weight ($x_j$) Normal Eq ($x_{\text{NE}}$) Std Error ($\text{se}$) 95% Conf. Interval VIF
▶ Stage 8 Spectral Decomposition: Covariance Matrix & Cyclic Jacobi Algorithm
📌
Concept: Eigen-decomposition of covariance $C = \frac{1}{n-1} B^T B = V \Lambda V^T$; equivalence to SVD $\lambda_i = \sigma_i^2 / (n - 1)$.
Purpose: Discovers orthogonal directions of maximum sample variance without matrix inversion.
Outcome: Computed eigenvalues and eigenvectors.
$$\text{Spectral Theorem: } \quad C = V \Lambda V^T, \quad C v_i = \lambda_i v_i, \quad \lambda_i = \frac{\sigma_i(B)^2}{n - 1}, \quad \sum_{i=1}^r \lambda_i = \text{tr}(C)$$
▶ Stage 9 Subspace Regularization: PCA vs PCR vs Ridge via SVD & Eckart-Young
📌
Concept: PCA variance rule vs cross-validated PCR vs Ridge singular shrinkage; Eckart-Young rank-k approximation.
Purpose: PCA drops low-variance directions without looking at target $b$; Ridge smoothly damps all directions by $\frac{\sigma}{\sigma^2 + \lambda}$, protecting predictive signal.
Outcome: Evaluated hyperparameter selection curves and compression.
$$\text{Ridge via SVD: } \quad x_{\text{ridge}} = V \left[\frac{\sigma}{\sigma^2 + \lambda} \odot (U^T b)\right], \qquad \text{PCR: } \quad x_{\text{pcr}} = V_{:, :k} \left[(U_{:, :k}^T b) \oslash \sigma_{:k}\right]$$
▶ Stage 10 Generalization Assessment: 5-Fold Cross-Validation Model Comparison
📌
Concept: Honest out-of-sample evaluation via 5-fold cross-validation with all scalers and basis selections refit inside each fold.
Purpose: Prevents data leakage; benchmarks linear models against a non-linear decision tree.
Outcome: Completed 5-fold cross validation.
$$\overline{\text{RMSE}} = \frac{1}{K} \sum_{k=1}^K \sqrt{\frac{1}{|V_k|} \sum_{i \in V_k} (y_i - \hat{y}_i)^2}$$
